# Study Planner

HTML, CSS, JavaScript 프런트엔드와 Node.js/Express 서버로 구성된 학습 일정 관리 앱입니다.

## 실행

Node.js 18 이상에서 실행합니다.

```sh
npm install
npm start
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. HTML 파일을 직접 열지 말고 서버 주소로 접속하세요.
포트는 `PORT` 환경 변수로 변경할 수 있습니다.

## 저장 방식

- 페이지를 열 때 `GET /api/schedules`로 일정과 과목별 색상을 불러옵니다.
- 등록은 `POST /api/schedules`, 수정과 완료 상태 변경은 `PATCH /api/schedules/:id`, 삭제는 `DELETE /api/schedules/:id`로 저장합니다.
- 과목별 색상은 `PATCH /api/courses/:subject/color`로 저장하며, 해당 과목의 모든 일정에 적용합니다.
- 서버는 변경 사항을 `data/study-planner.json`에 기록한 후 응답합니다. 파일 교체와 변경 요청의 순차 처리로 동시 요청에 의한 데이터 손실을 방지합니다.
- localStorage는 기존 일정의 일회성 서버 이전에만 사용합니다. 서버 저장에 성공한 이후 이전 데이터를 제거합니다.
- 저장 요청이 실패하면 화면에 오류를 표시하고, 마지막으로 서버에서 확인한 상태를 유지합니다. 처음 연결에 실패한 경우 ‘서버 확인’ 버튼으로 다시 불러올 수 있습니다.

서버를 재시작해도 데이터 파일은 유지됩니다. 백업할 때는 `data` 디렉터리를 보관하세요. `STUDY_PLANNER_DATA_DIR` 환경 변수로 저장 경로를 변경할 수 있으며, 배포 환경에서는 이 경로에 영구 볼륨을 연결해야 합니다. 동일한 데이터 파일은 한 서버 프로세스에서 사용하세요.

현재 모든 접속자는 같은 일정 데이터를 사용합니다.

## 검증

```sh
npm test
```

테스트는 임시 저장 디렉터리와 별도 포트를 사용하므로 실제 일정 데이터에 영향을 주지 않습니다. 일정 CRUD, 동시 수정, 완료 상태, 색상 유지, 입력 검증, 서버 재시작 및 기존 데이터 이전을 검증합니다.
